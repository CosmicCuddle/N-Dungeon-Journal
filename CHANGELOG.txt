v0.3.1 - Batch 1: Ragefire Chasm (2026-09-27)
---------------------------------------------
Fixes (3.3.5a compatibility / bugs)
- Main window background used Interface\FrameGeneral\UI-Background-Rock, which is a
  Cataclysm+ file and does not exist in the 3.3.5 client. Now uses
  Interface\DialogFrame\UI-DialogBox-Background.
- Boss portraits: the PlayerModel:SetCreature() portrait (black box) is replaced with static
  bundled portraits in Portraits\ plus a framed "?" fallback if a file is missing.
- Map: the black map panel is fixed. The Atlas RFC map is now bundled in Maps\ and loaded from
  Interface\AddOns\ServerDungeonJournal\Maps\RagefireChasm. Atlas BLPs are 512x512 and use the
  whole texture (Atlas shows them at 512x512, texcoords 0-1), so the map canvas is now square.
  Prev / 1/N / Next only appear for multi-floor maps. The map legend (A, 1-4) is shown beside it.
  The optional "use the installed Atlas addon" path and the hand-drawn fallback map were removed.
- Disabled placeholder maps for other dungeons no longer carry later-client Interface\WorldMap
  tile paths; they show a clear "not bundled yet" message.
- Loot: RFC boss drops were marked green (quality 2); AtlasLoot lists them as rare (blue, q3). Fixed.
- Uncached items: GetItemInfo() returns nil until cached. Rows now show the stored name/icon
  (GetItemIcon works uncached), the item is requested from the server with a hidden tooltip,
  and an OnUpdate poller refreshes the view when it arrives (3.3.5 has no GET_ITEM_INFO_RECEIVED).
- Shift-click now works for uncached items (requests them and asks you to click again) and uses
  HandleModifiedItemClick / ChatEdit_InsertLink / ChatFrame_OpenChat. Links are never hand-built.
- Boss text (who/abilities/mechanics) was clipped by a fixed 115px FontString; it now scrolls.
- Preparation rows used a fixed 55px spacing (long lines overlapped); now one scrolling text block.
- "Both factions" quests showed two faction icons; they now show plain "BOTH FACTIONS" text.
- SavedVariables are now initialised on ADDON_LOADED (tidy-up: the old file-scope table was
  simply replaced when the saved data loaded).
- Dungeon cover art: if a loading-screen texture fails to load, the card falls back to the bundled
  map instead of showing an empty or green texture.
- The browser order is now explicit (SDJ.ORDER), so per-dungeon data files can live in
  Data\Vanilla\ and RFC still appears first.

Ragefire Chasm content
- TRASH: 6 dangerous mob types with their abilities, a priority, and a short tip each.
  Trash loot: the 2 RFC trash quest drops. AtlasLoot has no RFC trash table, so no percentages.
- BOSSES: Oggleflint (optional), Taragaman the Hungerer, Jergosh the Invoker,
